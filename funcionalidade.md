# Funcionalidades

Implemente as funcionalidades nesta ordem de prioridade:

1. **Menu de navegação:** menu simples e fixo no topo, com links para as seções do portfólio. No celular, deve se adaptar a uma navegação compacta.
2. **Apresentação inicial:** seção de abertura com o nome Leonardo Moraes, uma frase de apresentação e um link para conhecer os projetos.
3. **Sobre mim:** seção com espaço para uma foto e um texto de apresentação. Não crie informações pessoais que não tenham sido fornecidas.
4. **Projetos:** galeria com imagem, título, breve descrição, tecnologias utilizadas e link para cada projeto. Se algum dado ainda não existir, deixe um campo fácil de substituir.
5. **Animações:** transições discretas e fluidas ao rolar a página, inspiradas no comportamento de rolagem do site Lusion. Evite animações excessivas ou que prejudiquem o desempenho.
6. **Contato:** seção com links de contato e formulário visual com validação no navegador. Deixe claro que o formulário não envia mensagens enquanto não houver um serviço de backend conectado.
7. **Tema claro/escuro:** opção para alternar entre os dois temas, mantendo contraste e legibilidade.

Todas as funcionalidades devem ser responsivas e funcionar em navegadores modernos.
