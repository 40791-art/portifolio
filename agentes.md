# Regras do projeto

- O projeto é um site de portfólio pessoal desenvolvido com HTML, CSS e JavaScript puro, sem frameworks.
- Antes de criar ou alterar qualquer coisa, leia estes arquivos: `referencia.md`, `identidade.md` e `funcionalidade.md`.
- Mantenha o código organizado, separando a estrutura em HTML, os estilos em um único arquivo CSS e as interações em um único arquivo JavaScript.
- Organize o HTML em seções identificadas e com nomes claros.
- Evite aparência genérica de template. Use as referências e a identidade visual descritas nos arquivos do projeto como inspiração, sem copiar os sites.
- O site deve funcionar bem em celulares, tablets e computadores.
- Priorize boa legibilidade, acessibilidade, carregamento rápido e navegação intuitiva.
- Não invente informações pessoais, experiências, habilidades ou projetos. Use somente os dados fornecidos pelo aluno; quando faltar alguma informação, deixe um espaço fácil de preencher.
- Depois de cada alteração, explique brevemente, em até duas linhas, o que foi feito.
